Selenium-Java-Framework_OrangeHRMProject is a scalable test automation framework built using Selenium WebDriver, Java, TestNG, and Maven to automate the OrangeHRM web application, following the Page Object Model (POM) design pattern.I applied OOP principles in my Selenium framework by using encapsulation to protect drivers, configuration data, and page locators; abstraction through BasePage, BaseClass, DriverManager, and ConfigReader; inheritance by extending BasePage and BaseClass; and polymorphism by using the WebDriver interface with different browser implementations such as ChromeDriver, FirefoxDriver, and EdgeDriver.
